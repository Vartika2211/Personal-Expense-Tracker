# Personal-Expense-Tracker
A responsive and interactive web-based Personal Expense Tracker that helps users monitor income, expenses, transactions, and spending patterns through a clean and intuitive dashboard
 ## Overview

The Personal Expense Tracker is a frontend web application designed to provide a simple overview of personal financial activity.

The dashboard displays:

- Monthly income
- Monthly expenses
- Recent transactions
- Expense categories
- Spending limits
- Income and expense overview charts

Users can also add new income or expense transactions using an interactive modal.
