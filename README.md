# Personal-Expense-Tracker
A responsive and interactive web-based Personal Expense Tracker that helps users monitor income, expenses, transactions, and spending patterns through a clean and intuitive dashboard
 
 ## Overview
The Personal Expense Tracker is a frontend web application designed to provide a simple overview of personal financial activity.
The dashboard displays:

Monthly Income
Monthly Expenses
Spending Limit
Recent Transactions
Expense Categories
Income and Expense Overview Chart

## Transaction Management

Users can add a transaction by entering:

Transaction Name
Amount
Transaction Type
Transaction Types
Income
Expense

When a transaction is added, it is dynamically displayed in the Recent Transactions section, and the corresponding income or expense total is updated.

# Expense Categories

The application currently displays the following expense categories:

Health
Entertainment
Shopping
Transport

Users can also select between:

Daily
Weekly
Monthly

## Interactive Features

 -Add transactions using the Add button.
 [Add transactions using the floating + button.
 -Remove the latest displayed transaction using the − button.
 -Switch between Day, Week, and Month views.
 -Select different months from the overview chart.
 -Highlight the active expense tab.
 -Open and close the transaction modal.

These interactions are implemented using JavaScript and DOM manipulation.
